# Images Directory

## Profile Photo
Add your profile photo as `profile.jpg` in this directory.

## Blog Post Images
Add blog post hero images to the `blog/` subdirectory.

### Recommended Image Sizes:
- **Profile photo**: 512x512px (square, will be displayed as circular)
- **Blog hero images**: 1200x630px (16:9 aspect ratio)

### Temporary Placeholders
Until you add your own images, you can use placeholder URLs in your markdown frontmatter:
```yaml
image: "https://via.placeholder.com/1200x630/3B82F6/FFFFFF?text=Your+Post+Title"
```

Or create simple placeholder images with any image editor.
